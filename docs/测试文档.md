# 系统测试文档

本文档记录校园约拍平台的测试方案、测试用例和测试结果，供论文"系统测试"章节参考。

## 一、测试概述

### 测试目标
验证校园约拍平台的功能正确性、算法有效性、系统稳定性，确保系统满足任务书和开题报告提出的功能与性能要求。

### 测试环境
| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 10/11 |
| 后端 | SpringBoot 3.2.5 + Java 21 |
| 前端 | Vue3 + Vite + Element-Plus |
| 数据库 | MySQL 8.0.46 |
| 测试工具 | JUnit 5（单元测试）、JMeter（压力测试） |

### 测试方法
- **单元测试**：针对核心算法（余弦相似度推荐、DFA 敏感词过滤）编写 JUnit 测试，验证算法正确性。
- **功能测试**：对系统各功能模块进行端到端流程测试，验证业务逻辑正确性。
- **压力测试**：使用 JMeter 对核心接口进行并发测试，验证系统稳定性。

## 四、压力测试方案（JMeter）

### 4.1 测试目标
验证核心接口在并发场景下的稳定性，满足"多用户并发访问的性能需求"。

### 4.2 测试场景
| 场景 | 接口 | 并发数 | 循环次数 | 目标 |
|------|------|--------|---------|---------|
| 登录接口 | POST /api/auth/login | 100 | 10 | 响应时间 < 1s |
| 需求列表 | GET /api/demand | 100 | 10 | 响应时间 < 1s |
| 推荐接口 | GET /api/recommend/photographers | 50 | 10 | 响应时间 < 1s |
| 订单创建 | POST /api/order | 50 | 5 | 无重复订单，防超约生效 |

### 4.3 JMeter 操作步骤
1. 下载并解压 Apache JMeter（https://jmeter.apache.org/）
2. 启动 `bin/jmeter.bat`
3. 新建线程组（Thread Group），设置并发数、循环次数
4. 添加 HTTP 请求（HTTP Request），配置接口地址
5. 添加 HTTP Header Manager，设置 `Authorization: Bearer <token>` 和 `Content-Type: application/json`
6. 添加监听器（聚合报告 Aggregate Report、查看结果树 View Results Tree）
7. 运行，查看平均响应时间、吞吐量、错误率

### 4.4 预期性能指标
- 平均响应时间 < 1 秒
- 错误率 < 1%
- 并发 100 用户下系统稳定运行
